This is a tool written using Claude Code to extract data from FF8 source files in a format the project can use.

It is not "vibe" based, it is based upon extensive research conducted in the following works:
https://github.com/myst6re/deling
https://github.com/klavierworks/wmset_parser
https://github.com/klavierworks/charone_extractor
https://hobbitdur.github.io/FF8ModdingWiki/

It aims to bring together all these separate efforts in to a standlone "all in one" util.
